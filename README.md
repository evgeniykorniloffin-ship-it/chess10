# chess10
Шахматная программа с графическим интерфейсом и исходным кодом. 
* Система: Windows 10 - 64bit.
* Запуск: start.cmd
## О программе.
Это моя старая битбоард программа, которую я немного модифицировал и перекомпилировал на clang.
* Основные эвристики:
1. Поиск 2 этапа, основной без подрезок, и выборочный
2. Недействительное перемещение.
3. Выборочный поиск - первый лучший, остальные если не взятия и шахи сокращаются по формуле предотвращающей экспоненциальный взрыв поиска. Используются внутренние итеративные углубления для поиска лучшего хода. Хеш примитивный - вставлять всегда, из за IID это работает. PV поддерживается динамически через IID - это минус. В целом - играть можно.

Не мог скомпилировать под 64 бит, какой то скрытый баг, раньше на вижуал си 2005 все шло на ура а сейчас только clang_cl помог. В общем играть можно, программа шустрая и не жестит как машина.
Приятной игры!
